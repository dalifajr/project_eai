RENCANA PENGEMBANGAN PROJECT IMPLEMENTASI ENTERPRISE APPLICATION INTEGERATION (EAI)

Rencana ini adalah rancana pengembangan project implementasi enterprise application integration (EAI) berbasis web yang akan dibuat pada mata kuliah Enterprise Application Integration (EAI). Project ini akan membahas mengenai sistem informasi akademik yang terintegrasi dengan sistem informasi akademik lainnya. dalam hal ini adalah aplikasi total billing system. jadi, nanti akan ada 2 aplikasi berbeda, yaitu simak dan juga total billing system.

dimana ketika user mahasiswa belum melunasi ukt, maka mahasiswa tersebut tidak dapat mengambil krs dan mendaftar wisuda. pastikan juga mahasiswa yang ingin mendaftar wisuda sudah menyelesaikan ujian skripsi.

user yang ada pada aplikasi simak; mahasiswa, admin.
user yang ada pada aplikasi total billing system adalah admin.

untuk teknologi yang digunakan adalah:
1. laravel 13 fullstack
2. mysql dari laragon.

saya ingin agar 2 aplikasi ini akan bisa saling berkomunikasi dalam pertukaran data melalui API. jadi, nanti akan ada API yang akan digunakan untuk pertukaran data antar aplikasi. dan ada aplikasi tersendiri untuk sistem informasi akademik (SIMAK). dan total billing system.

gunakan skill yang saya pasang seperti antislop untuk membuat desain aplikasi simak dan total billing system. saya ingin agar kedua aplikasi tersebut memiliki looks moderen simple and clean.

gunakan pula gambar diagram yang ada pada folder untuk djadikan referensi.

jelaskan pula mekanisme dan alur sistem yang dibuat, serta metode komunikasi data, tabel, dll.
